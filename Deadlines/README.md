# Deadlines

Internal deadlines and the monthly close calendar. **Statutory dates (SARS/CIPC) live in `Context/deadlines-sa.md`** — this folder is for everything internal.

```
Deadlines/
├── tracker.md         Live list: what's due, owner, status
└── monthly-close.md   The month-end close checklist + target dates
```

`/deadlines` reads both of these plus the statutory calendar and tells her what's due and what's overdue.

Suggested `tracker.md` row:
`- [ ] <deadline> — owner: <name> — due: <YYYY-MM-DD> — status: <not started / in progress / done>`
