# Team

One file per team member: what they own and the deliverables/deadlines tied to them.

```
Team/
└── <name>.md
```

Suggested contents:
```markdown
# <Name> — <role>

## Owns
- <area: AP / AR / payroll / reporting / tax>

## Recurring deliverables
- <deliverable> — cadence — due <when>
```

`/team` matches deliverables to owners and shows who's behind, with chase drafts ready.
